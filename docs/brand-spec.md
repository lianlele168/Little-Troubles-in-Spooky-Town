# Little Troubles Guide - Visual Source Spec

This is an unofficial walkthrough and task tool. Its visual direction comes from the official pastel town screenshots, while the information design is original.

## Source assets

- `public/cover.png`: official itch.io cover and compact icon source
- `public/gameplay-town-wide.png`: official title-screen image and primary hero
- `public/gameplay-town.png`: official lower-town gameplay screenshot
- `public/gameplay-beach.png`: official central-town gameplay screenshot
- `public/gameplay-island.png`: official lighthouse and flower-shop screenshot

Source page: https://kenney.itch.io/little-troubles-in-spooky-town

## Palette

- Ghost ink: `#30223f`
- Soft ink: `#604b6b`
- Paper: `#fbf8fd`
- Lilac: `#8968b8`
- Mint: `#58aa87`
- Apricot: `#e68b60`

Lilac carries identity, mint marks route progress and verified facts, and apricot calls attention to tips or requirements. White and paper remain the dominant surfaces so the interface does not become a one-note purple theme.

## Typography and composition

- Fredoka is reserved for names, headings, numbers, and the playful game identity.
- Nunito Sans handles navigation, controls, and guide copy.
- The home hero uses an actual game screenshot with text over it, never a fabricated illustration.
- Repeated task entries may use cards; normal page sections remain unframed bands.
- Cards and tools use an 8px radius or less.
- Task numbers always mean recommended route order, not official numbering.
- Functional controls use Lucide icons and visible focus states.
