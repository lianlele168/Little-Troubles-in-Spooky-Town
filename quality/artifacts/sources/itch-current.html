Little Troubles in Spooky Town

Download Now

In Little Troubles in Spooky Town the goal is to prove to everyone that you can be whatever you want to be! ✨

🎮 Controls

  • Left joystick (or WASD): Move around
  • A button (or E): Interact
  • B button (or Spacebar): Jump
  • Y button (or I): Change outfit
  • X button (or F): Drop item
  • D-pad up (or T): Task list

✨ Credits

  • Game by Kenney
  • Featuring music by Samantha van der Sluis
  • Technology by Unity, Super Text Mesh (dialogue)
  • Made during Girly Game Jam in 9 days development time

🧰 Troubleshooting

  • MacOS is unsupported
  • If you run into any problems (visual issues, performance or input support) I'd recommend getting the downloadable version below.
  • If there's still performance issues, change the visual quality through the in-game options.
  • If your gamepad isn't working on Chrome navigate to 
    chrome://flags
    and make sure that 
    Enable GameInput data fetcher
    is set to enabled.

Human-made, no AI was used during any part of the process.
