In Little Troubles in Spooky Town the goal is to prove to everyone that you can be whatever you want to be! ✨
🎮 Controls
Left joystick (or WASD):
Move around
A button (or E):
Interact
B button (or Spacebar):
Jump
Y button (or I):
Change outfit
X button (or F):
Drop item
D-pad up (or T):
Task list

MacOS is unsupported
If you run into any problems
(visual issues, performance or input support)
I'd recommend getting the downloadable version below.
If there's still performance issues, change the visual quality through the in-game options.

chrome://flags
and make sure that
Enable GameInput data fetcher
is set to enabled.
